# Image linking for mods

Images used in the CurseForge descriptions of whatarewedoinghere's Hytale and Minecraft mods. Hosting them here keeps them out of the CurseForge gallery.

- `insight/` – Insight banner, section headers and feature images
- `lodestar/` – Lodestar banner, section headers and feature images
- `viewfinder/` – Viewfinder banner, section headers and feature images
- `scrawl/` – Scrawl banner, logo, section headers and feature images
- `layeredflooring/` – Layered Flooring banner, icon, section headers and feature images
- `anomalies/` – Anomalies banner and feature images
- `bodysnatcher/` – Body Snatcher (Minecraft) banner, logo and feature images

Link format: `https://raw.githubusercontent.com/groundedbeefy/image-linking-for-mods/main/<folder>/<file>.png`
- `anomalyanchors/` — Anomalies & Anchors (Minecraft)
- `fieldnotes-menus/` — Field Notes Menus (Minecraft)
